🚀 部署說明

此網站可以立即部署到以下平台：

  • GitHub Pages：推送到 GitHub 並啟用 Pages
  • Netlify：拖放資料夾或連接 Git 儲存庫
  • Vercel：自動從 GitHub 部署
  • 任何靜態主機：上傳所有檔案即可

💡 部署後，Mermaid.js 將從 CDN 正常載入，所有功能將完全運作。

✨ 功能特色

  • 即時預覽：編輯器中的變更會自動更新預覽（500ms 延遲）
  • 語法編輯：完整的文字編輯器，支援多行編輯
  • 修改功能：所有語法都可以自由修改
  • 恢復預設：一鍵恢復到原始範例程式碼
  • 錯誤處理：語法錯誤時顯示友善的錯誤訊息
  • 響應式設計：桌面和行動裝置都能正常使用
